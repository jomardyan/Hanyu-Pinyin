Hanyu Pinyin Reader Support

Hanyu Pinyin Reader adds local Pinyin pronunciation annotations to Chinese text on webpages.

Common checks

  • The extension cannot modify Chrome internal pages, the Chrome Web Store, or other protected browser pages.
  • Use the popup to confirm the extension is enabled globally and not disabled for the current domain.
  • Use Advanced settings to restore defaults if appearance or exclusion settings prevent expected annotations.
  • Reload the webpage after updating the extension if a page was already open.

Privacy

The extension processes page text locally. See the Privacy Policy published alongside this support page.

Support contact

Use the developer support contact shown on the Chrome Web Store listing for bug reports and questions.
