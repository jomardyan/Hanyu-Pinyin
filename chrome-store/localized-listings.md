# Localized Chrome Web Store descriptions

Use the matching language in the Store listing tab. The product name and short description come from `public/_locales/<locale>/messages.json`; the detailed description is copied from the matching section below. English copy remains in `listing.md`.

This set prioritizes Chinese-language readers and common Chinese-learning audiences. It is an audience choice, not a ranking by worldwide speaker counts.

The extension's popup and settings interface currently remain in English. These translations cover the Chrome Web Store title, summary, keyboard command descriptions, and detailed listing text. Screenshots still show the English interface.

## zh_CN — 简体中文

**名称：** 汉语拼音阅读器

**简短说明：** 在中文网页上显示本地生成的拼音注音。支持词组、声调、外观、划词操作和网站设置。

**详细说明：**

汉语拼音阅读器直接在网页的中文文字上添加读音标注，帮助学习者阅读简体和繁体中文，同时保留原文。拼音可显示在文字上方、文字后方、悬停时，或完全隐藏。

主要功能：

- 根据词语和短语生成汉语拼音；可按词或按字标注。
- 支持声调符号、声调数字和不显示声调。
- 调整拼音的大小、透明度、间距和颜色。
- 为不同网站设置启用或停用规则。
- 对选中的文字显示或复制拼音，并支持键盘快捷键。
- 支持动态加载的网页和常见的单页应用。

中文文字仅在浏览器本地处理，不会发送给开发者或远程拼音服务。偏好设置和网站规则保存在本地。扩展程序不含广告、分析或跟踪功能。受保护的 Chrome 页面、Chrome 应用商店、浏览器 PDF 查看器，以及使用封闭 Shadow DOM 的页面无法正常标注。

## es — Español

**Nombre:** Hanyu Pinyin Reader

**Descripción breve:** Lee páginas en chino con pinyin generado en tu navegador. Ajusta tonos, aspecto, selección de texto y sitios web.

**Descripción detallada:**

Hanyu Pinyin Reader añade guías de pronunciación al texto chino de las páginas web. Funciona con chino simplificado y tradicional y conserva el texto original. Puedes mostrar el pinyin encima o después del texto, solo al pasar el cursor, u ocultarlo.

- Reglas para activar o desactivar la extensión en cada sitio web.
- Mostrar o copiar el pinyin del texto seleccionado y usar atajos de teclado.
- Compatibilidad con páginas de carga dinámica y aplicaciones web de una sola página habituales.

El texto chino se procesa localmente en el navegador. No se envía al desarrollador ni a un servicio remoto de pinyin. Las preferencias y reglas de sitios se guardan de forma local. No hay publicidad, analíticas ni seguimiento. Las páginas protegidas de Chrome, Chrome Web Store, los visores de PDF del navegador y las páginas con Shadow DOM cerrado no se pueden anotar.
