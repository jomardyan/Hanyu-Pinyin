# Chrome Web Store assets

This directory contains the files prepared for the Chrome Web Store listing.

Required listing graphics generated by the release process

- 128 by 128 store icon
- 440 by 280 small promotional tile
- Five 1280 by 800 screenshots

Optional listing graphics generated by the release process

- 1400 by 560 marquee promotional image

Submission documentation included

- Store listing copy
- Localized titles, summaries, and detailed descriptions for ten additional languages in `localized-listings.md`
- Privacy policy copy
- Reviewer notes
- Submission checklist
- Public privacy and support page templates in `docs`

Generate and package the complete submission locally with

```bash
npm install
npm run store:release
```

The command creates `release/hanyu-pinyin-reader-1.0.0-chrome-web-store.zip` for the Package tab and `release/hanyu-pinyin-reader-1.0.0-store-assets.zip` for the listing materials. Store marketing assets are intentionally excluded from the runtime extension ZIP.

A public HTTPS privacy policy URL must be configured in the Chrome Web Store dashboard before public submission. The repository includes `docs/privacy.html` as a ready-to-host template.

The localized titles and summaries are included in the extension package under `public/_locales`. After uploading that package, select each supported language in the Store listing tab and paste its detailed description from `localized-listings.md`. The popup, settings, and screenshots currently use English text.
