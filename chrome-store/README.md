# Chrome Web Store assets

This directory contains the files prepared for the Chrome Web Store listing.

Required listing graphics included

- 128 by 128 store icon
- 440 by 280 small promotional tile
- Five 1280 by 800 screenshots

Optional listing graphics included

- 1400 by 560 marquee promotional image

The extension upload ZIP is generated by GitHub Actions from the production `dist` directory. Store marketing assets are intentionally not copied into the extension package.
